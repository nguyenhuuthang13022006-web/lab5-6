# Lab 6 - Phân trang, lọc và tìm kiếm Learner

Project ASP.NET Core MVC .NET 10. Danh sách mẫu lưu trong bộ nhớ (khởi động lại ứng dụng sẽ nạp lại dữ liệu mẫu).

- Mỗi trang hiển thị 3 learner.
- Lọc theo IT, Economics, Mathematics.
- Tìm theo tên hoặc họ.
- Bộ lọc và từ khóa được giữ khi chuyển trang.
- Có Create, Edit, Delete cơ bản.

Mở `Lab6_PhanTrang_Loc_TimKiem.csproj` bằng Visual Studio 2026, Restore, Build, rồi Ctrl+F5.
